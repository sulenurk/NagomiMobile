# Nagomi Mobile

Nagomi Mobile is the Android version of [Nagomi Desk](#), redesigned for phones and tablets.

It brings Nagomi’s focus, study planning, and productivity tools to Android devices with responsive layouts for both portrait and landscape orientations.

## Features

- Pomodoro timer
- Focus Timer
- Study Plan
- Subject management
- Statistics
- Customizable focus and break durations
- Alarm and notification settings
- Responsive phone and tablet layouts
- Portrait and landscape tablet support
- Dark-themed interface
- Local data storage
